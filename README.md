# MCF VideoCut — installateurs

Ce dépôt ne contient que les **installateurs Windows** de MCF VideoCut (pas de code source).
L'application installée y vérifie elle-même ses mises à jour : chaque version est accompagnée
d'un manifeste `latest.yml` signé (Ed25519), refusé par l'application si la signature est invalide.

Télécharger la dernière version : onglet **Releases**.
